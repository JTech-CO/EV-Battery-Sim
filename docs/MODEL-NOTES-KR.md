# EV Battery Sim - 모델 노트

## 1. 범위
브라우저에서 DFN/P2D PDE 솔버가 실제로 실행되는 것처럼 보이게 하지 않고, 출처 기반 평형 전기화학과 명시적인 축약 동적 모델을 결합한다.

## 2. 평형 전기화학
SOC를 BPX의 음극·양극 stoichiometry 구간에 선형 매핑한다. 충전될수록 음극 stoichiometry는 증가하고 양극은 감소한다. 임의 문자열 `eval` 없이 하드코딩한 출처 OCP 적합식을 평가한다.

`U_ocv = U_p(x_p) - U_n(x_n)`

## 3. 동적 단자전압
2-RC Thevenin 근사를 사용한다.

`V = U_ocv - I R0 - V1 - V2`

`dVi/dt = -(Vi/taui) + I Ri/taui`

전류는 방전 양수 규약이다. R0/R1/R2/tau 값은 `assets/data/model-priors.json`의 엔지니어링 prior이며 BPX 실측 파라미터가 아니다.

## 4. 열 모델
셀 전체를 하나의 집중정수 열 노드로 취급한다.

`C_th dT/dt = Q_gen - h A_ext (T - T_amb)`, `C_th = rho cp V`

진단값은 `Q_irr = I(U_ocv - V)`, `Q_rev = - I T dU_ocv/dT`를 사용한다. 코어-표면 온도구배를 독립적으로 예측하지 못한다.

## 5. 차량과 팩
US06은 속도 프로파일이며 배터리 전류 데이터가 아니다. 관성·구름저항·경사·공기저항에서 휠 전력을 구하고, 구동/회생 효율과 보조 부하를 거쳐 팩 전력을 계산한다. 이상화된 `Ns × Np` 토폴로지에서 셀 전류를 구한 뒤 C-rate와 출처 전압 한계를 적용한다. 셀 편차, 버스바, 밸런싱, 컨택터 및 공간 열망은 포함하지 않는다.

## 6. 열화 screening
절대 Ah 처리량과 EFC를 추적한다. 선택형 SOH 감소 및 석출/열화 위험 점수는 탐색용 prior이며, 검증된 SEI 두께·LLI·LAM·석출 리튬 질량이 아니다.

## 7. 검증 경로
NMC 프리셋은 공개 1C 기준곡선 시간점에서 축약 모델의 전압을 비교해 RMSE와 최대 절대오차를 표시한다. 이는 동일 계열의 기준곡선 비교이지 독립 홀드아웃 검증이 아니다.
